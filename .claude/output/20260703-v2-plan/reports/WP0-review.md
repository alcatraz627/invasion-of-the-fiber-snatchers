# WP0 skeptical review — V2 core substrate

Scope: `git diff cacea06..HEAD -- src bin tests` (27 files, +2210). Reviewed against
IMPLEMENTATION.md §2 frozen contracts + §3 WP0 acceptance, reports/WP0.md (known
deviations excluded), tests/VALIDATION.md. `bun test` run by reviewer: 18/18 pass.
Findings marked **[probed]** were reproduced live against the fixture app via the real
CLI → daemon → browser path (probe transcript at the bottom); the rest are grounded in
code reading with the cited lines.

Verdict: the substrate shape is right (one pipeline, shaped errors, real-socket tests),
but four load-bearing signals that Wave 1 builds on are broken today: digest integrity
under concurrency, ref/generation identity, dead-click purity, and component targeting.
None of the four is covered by the acceptance suite; three were trivial to reproduce.

## Positive observations (earned, not charity)

Real-socket protocol tests with out-of-order correlation and mid-request push; failures
journal too; the FsErrorShaped/PipelineResult never-throw seam in runAction held up under
every probe (no raw throw escaped to the CLI); env-access convention honored by all V2
code (single FS_CONFIG_CWD read through env.ts); stale-socket recovery after SIGKILL is
self-healing; comment register is largely clean and why-oriented.
